How Pounce works
  1. Drag blocks into the Script. They run from top to bottom.
  2. set makes a variable: a box with a name that holds a value.
  3. while repeats the blocks inside it as long as its question is true. Make sure something inside changes, or it never stops!
  4. Press Run. The Console shows what happened. Red blocks mean something needs fixing.

Modules for shuck: none
